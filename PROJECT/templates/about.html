Instructor Instructions Compliance Checklist

Includes dataset name, source link, 100,000 transaction instances across 1,000 customer accounts, target variable (is_laundering), and class distribution (98.83% Normal vs 1.17% Laundering).

0 missing values, 0 duplicates, One-Hot Encoding for transaction types, StandardScaler fitted strictly on the 80% training set ($X_{train}$) and tested on $X_{test}$ with verified zero data leakage.

Descriptive statistics, class balance breakdown, transaction type distributions, amount boxplots, and correlation heatmaps with text observations under each figure.

15 features created: customer historical means, amount z-scores, 7-day rolling velocity counts, structuring flags ($8,500 - $9,999), and temporal calendar attributes.

6 machine learning architectures evaluated under 5-Fold Stratified Cross-Validation with hyperparameter optimization for Random Forest and XGBoost.

Comprehensive evaluation across Accuracy, Precision, Recall, F1-Score, ROC-AUC, and Confusion Matrices. Champion Model: Gradient Boosting (99.86% Accuracy, 0.9386 F1-Score, 0.9995 ROC-AUC).

Interactive real-time prediction screener deployed in this web application with automated compliance explanations and batch CSV audit reporting.
